# GT3 orbital camera v0.4

**PBPX-95503 · CRC 8AA991B0 · PCSX2**

Download [8AA991B0_orbital-nativa.pnach](8AA991B0_orbital-nativa.pnach). Enable `Camera/Orbital nativa - analogico direito` and restart without a savestate.

- Right stick horizontal: proportional angle, up to 180° per side. Release returns smoothly behind the car.
- Right stick vertical: adjust pitch; release holds.
- `[` / `]` → port-2 L1 / R1: move closer/farther.

Use DualShock 2 on port 1 and port 2 for the keys. Original FOV retained. Use one camera mod at a time.

# Câmera orbital · GT3 · v0.4

**PBPX-95503 · CRC 8AA991B0 · PCSX2**

- Analógico direito horizontal: ângulo proporcional, até 180° por lado. Soltar retorna suavemente para trás do carro.
- Analógico direito vertical: ajusta a inclinação e mantém ao soltar.
- `[` aproxima; `]` afasta. Altura fixa; FOV original do jogo.

Copie [8AA991B0_orbital-nativa.pnach](8AA991B0_orbital-nativa.pnach) para a pasta de cheats do PCSX2. Habilite `Camera/Orbital nativa - analogico direito` e reinicie o jogo.

Na porta 1, use DualShock 2 com o analógico direito mapeado. Para as teclas de distância, selecione DualShock 2 na porta 2 e mapeie `[` para L1 e `]` para R1. No Steam Deck, use seus próprios binds.

Use somente um mod de câmera. O analógico direito deixa de controlar acelerador/freio. Para desativar, desmarque o grupo e reinicie.
